# BALFDAR Admin

This project contains the Admin dashboard, authentication, shared customer/API routes, SQLite database, invoices, WhatsApp order flows, and product uploads. Run `npm install`, then `npm run dev` to start it on port 3003. Keep the existing credentials in `.env`; set `BALFDAR_STORE_ORIGIN` and `NEXT_PUBLIC_SITE_URL` to the public Store origin when deploying.
